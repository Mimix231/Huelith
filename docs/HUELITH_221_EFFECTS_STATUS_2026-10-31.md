# Huelith — 221 Effects: Intended vs. Current Source (31 October 2026)

**This is an implementation ledger, not a professional-quality certificate.** This document supersedes the 30 October source-status column while retaining the original artistic descriptions and assessments for reference. The 120 expanded processors were preserved; the **90 formerly unseparated original effects were given dedicated dispatchable modules** in this pass. The 11 original effects already separated in the prior Project Fluidity work were preserved. **101/101 original catalog IDs now route to individually owned processing files** (some use shared primitives or the previously developed spatial-blur backend).

**Verification:** Targeted full effect compilation and dispatcher compilation pass; **101/101** original catalog effects produced an observable result on the Chromium synthetic reference image with no runtime exception; **22/22** Signature FX returned exact neutral output at amount zero in the Signature FX browser test; 90 newly routed IDs are covered by dedicated source-registry checks. Headless browser rendering is not equivalent to verifying the complete Tauri desktop build, exports, playback or GPU accelerated paths. More stringent, per-effect artistic and parameter certification remains outstanding.

**Performance limit:** Chromium headless CPU standalone at 1920 × 1080 (sample): Curves **25.5 ms**, Exposure **119.9 ms**, Gamma **108.3 ms**, Vibrance **97.2 ms**, Oil Painting **849.7 ms**, Spectrum Glow **1020.9 ms**. Conditions fluctuate and do not prove Windows/GPU latency. **The requested 20–50 ms universal slider-to-image target is NOT achieved.** An authoritative GPU-native path for all effects and measured Windows workflow remain missing.

**Parameter follow-up:** A scalar end-point sweep found 27 no-change observations in this reference scene. These include periodic angle end points (-180° and 180°), conditional controls (e.g. Bloom threshold only in bloom mode, silhouette detection on a transparent image), and potentially weak/inert controls. We do **not** label these 27 as universally broken or complete without testing intermediate and context-appropriate values.

**Historical columns:** "What it SHOULD do" remains the artistic design target. "What it ACTUALLY does" includes descriptions of the individual source implementation; it does not certify that the result visually matches its name. Previous assessments have not automatically become "Mostly aligned" merely because a module exists.
