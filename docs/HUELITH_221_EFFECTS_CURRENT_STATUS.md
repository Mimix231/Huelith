# Huelith — 221 catalog effects: comparison after dedicated-source migration

**30 October 2026 — read-only status snapshot, not a release or completion certificate.**

Based on the latest `huelith_effect_work` implementation, itself based on the updated `Huelith[Dev](1).zip` source plus the prior ongoing working changes.

**What is demonstrably different:** All **120 of 120 expansion entries** now have unique named TypeScript effect modules under `src/editor/effects/`, a mandatory registry, and a shared authoritative source-to-image processing dispatch for cooperative previews and export. The old monolithic placeholder switch in `expansion-120.ts` has been eliminated. The remaining **101 of 221 catalog entries** were **not individually rebuilt** in this pass. Some independent modules still use artistic/optical approximations, not fully physical media simulation. **No effect is marked finished or professional-grade merely because it has a processor file.**

**Performance reality:** On this environment's CPU at 1920×1080, exact initial renders ranged widely; even where the expensive preparation is cached, many filters exceeded 25–30ms. The result is NOT a proof of 25–30ms per update, 60fps, Windows Tauri runtime operation, or shader acceleration. User-visible playback, project-open/save, animated effects, and native installation still require real desktop verification.

**Tests:** Strict targeted TypeScript effect compilation (`tsc --noEmit -p tsconfig.effects.json`); **632/632** repository Node tests; 120/120 processors preserve source immutability and have distinct nontrivial pixel output on the test image; control-change, transparency, preview/export tests on representative subsets. These do not establish effect-name visual fidelity for all scenes.

The historical classification in the last column is a prior assessment, not automatically revised by code migration. Descriptions in the "ACTUALLY does" column are drawn from implementation comments/source and should be viewed as algorithm summaries, not promises that the result is optically/materially faithful. Dedicated processors are **TypeScript**, not Rust.
