## Known v0.2 Alpha Limitations
- Guided foreground segmentation is available, but neural semantic recognition is not yet implemented; difficult white-on-white subjects still need user guidance.
- Full-resolution complex GPU acceleration is incomplete.
- Heavy 4K effect stacks may render well below 60 FPS.
- Four-corner Mesh is not a deformable arbitrary-N×M mesh.
- Full native Windows build and installer certification require an installed toolchain.
- Effect parameter animation is intentionally **not** part of Phase AI: effects are persistent at the layer level.
