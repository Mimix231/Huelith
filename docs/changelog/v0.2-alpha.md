## Current 0.2-alpha Limitations
- Huelith Cutout is manual-first. Selecting intricate characters requires lasso/brush work; it does not automatically recognize subjects.
- Old Remove Background effect settings remain readable for legacy document compatibility, but the effect is no longer offered as a new operation.
- Full native GPU acceleration is incomplete; computationally expensive effects can reduce playback responsiveness.
- The four-corner gradient Mesh is not an arbitrary N×M mesh.
- Animation layer effects persist across frames; effect-parameter animation is not part of this release.
- Full TypeScript/Vite and Windows/Tauri installer certification requires a machine with the complete build toolchain.
